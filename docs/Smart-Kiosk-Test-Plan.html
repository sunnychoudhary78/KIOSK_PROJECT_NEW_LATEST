TESTER GUIDE

Smart Kiosk

Feature checks for the desktop kiosk

Use this at the machine. Each check says what to do, what you should see, and what counts as a fail. Write Pass or Fail on the last page. If it fails, note the exact words on the screen.

Before you start. The kiosk is already activated and shows the home menu. The printer has A4 paper. You have a phone with a camera. Some checks need extra gear, and only those checks: a DigiLocker account, the fingertip and temperature sensor, the charging socket, and the palm camera.

How to mark a result

  • Follow the steps in order inside a feature. You can test the features in any order.
  • Pass only when the “Pass when” line is true. If any part of it is missing, mark Fail.
  • Do not treat a crash, a frozen screen, or a message you cannot act on as a pass.
  • After a fail, tap Home so the next check starts clean.

Home and leaving a visit

The home screen is the start and end of every visit. These checks apply to every feature.

H1
Do: Stand at the home screen after the kiosk has started.

Pass when: You see six tiles: Print, DigiLocker Print, Well Being, Phone Charging, Astrology, and Fuel stations.

Fail when: A tile is missing, the screen stays on Activating, or it shows Can’t reach the server.

H2
Do: Open any service, then tap Home.

Pass when: You return to the six-tile menu. The next person does not see the previous visit.

Fail when: Home does nothing, or the previous documents, form, or result are still on screen.

H3
Do: Open a service and do not touch the screen for about 2 minutes.

Pass when: A prompt asks “Are you still there?” If you ignore it, the kiosk returns home after a short countdown. Tap the screen during the countdown and you stay in the service.

Fail when: The kiosk never warns you, or it wipes the visit while you are still using it.

H4
Do: With the printer out of paper, start a print from Quick Print, OTP Print, or DigiLocker.

Pass when: Printing pauses and the screen says the printer is out of paper, in plain words.

Fail when: The kiosk says the print succeeded while no pages come out, or the message is a code you cannot act on.

Print

Print has two paths. Quick Print uses a QR code and the phone browser. OTP Print uses a 6-digit code from the Smart Kiosk mobile app.

Quick Print

P1
Do: On the home screen, tap Print.

Pass when: You are asked how you want to print, with “Print from this phone” and “I have an OTP”. Cancel returns home.

Fail when: Only one path is offered, or Cancel leaves you stuck.

Q1
Do: Choose Print from this phone.

Pass when: A QR code appears, with a countdown until the session expires. The screen says to scan with the phone camera and upload in the browser. No app is required.

Fail when: There is no QR code, or the phone cannot open the upload page.

Q2
Do: Scan the QR, upload one PDF from the phone browser, then return to the kiosk.

Pass when: The document appears on the kiosk. You can preview it, see the page count, tap Print, and the screen then says to collect the pages from the printer. The pages are the file you uploaded.

Fail when: The file never appears, preview is blank, or the printed pages do not match the PDF.

Q3
Do: Start Quick Print again and tap Cancel before uploading.

Pass when: You leave the session cleanly and can start again from Home.

Fail when: The old QR session is still waiting when you come back.

Q4
Do: On the phone page, try to upload a file that is not a PDF.

Pass when: The upload is refused and you are told that only PDF files can be printed.

Fail when: A non-PDF is accepted or the kiosk crashes.

Q5
Do: Show the QR code and wait until the countdown ends. Do not upload.

Pass when: The session expires and you can start a new one. An upload after expiry does not print.

Fail when: An expired code still accepts a file and prints it.

OTP Print

O1
Do: On a phone, create a print OTP in the Smart Kiosk app. On the kiosk choose I have an OTP and enter the 6-digit code on the on-screen keypad.

Pass when: The documents linked to that code appear. The screen says you can use the keypad and do not need a phone keyboard.

Fail when: A correct code is rejected, or the keypad misses digits.

O2
Do: Preview a document, then tap Print.

Pass when: The kiosk prints that document and tells you to collect the pages.

Fail when: Preview and print show different files, or nothing comes out while the screen says success.

O3
Do: Enter a wrong 6-digit code.

Pass when: The screen says the OTP is invalid or already used. You can try another code.

Fail when: A wrong code opens someone else’s documents, or the screen freezes.

O4
Do: Redeem a code that has no documents, or an expired code.

Pass when: You see a plain message such as no documents, or that the OTP has expired. New OTP lets you start again.

Fail when: The kiosk shows a blank list with a Print button that still runs.

DigiLocker Print

The visitor signs in to DigiLocker on the kiosk, picks a government document, previews it, and prints it.

D1
Do: Tap DigiLocker Print and complete sign-in when the DigiLocker page opens.

Pass when: The kiosk shows Starting DigiLocker, then your linked documents after you allow access.

Fail when: Sign-in never starts, or it returns home with no explanation.

D2
Do: Select a document, preview it, and tap Print.

Pass when: You see the preview first. After printing, you are told to collect the pages, and those pages match the document.

Fail when: Print starts with no preview, or the paper is a different file.

D3
Do: Tap End session or Home before printing.

Pass when: The DigiLocker visit ends and the home menu is shown. The next person is not still signed in.

Fail when: Documents from the previous person are still listed.

D4
Do: Finish sign-in but do not share any documents.

Pass when: The screen says no DigiLocker documents were shared for this session.

Fail when: It shows an empty screen with no way back, or it prints nothing and calls that success.

Well Being

Two measurements share one screen: blood oxygen with heart rate, and body temperature. Only one runs at a time.

W1
Do: Tap Well Being with the USB sensor connected.

Pass when: You can choose Blood Oxygen or Temperature. The screen says only one sensor runs at a time.

Fail when: Neither choice is offered while the sensor is plugged in, or both start together.

W2
Do: Choose Blood Oxygen. Rest a fingertip on the sensor and keep still for about 15 seconds.

Pass when: The screen guides finger placement, then shows a heart rate in BPM and a blood oxygen (SpO₂) result. It says you may remove your finger.

Fail when: It never detects the finger, or it shows a result with no numbers.

W3
Do: Start Blood Oxygen, then lift your finger before it finishes.

Pass when: The measurement is cancelled and you return to the two choices.

Fail when: It keeps counting with no finger, or it saves a result anyway.

W4
Do: Choose Temperature. Hold your forehead about 1–2 cm from the sensor and stay still.

Pass when: The screen guides you, then shows a temperature reading.

Fail when: It never starts, or the result has no temperature.

W5
Do: Unplug the sensor and open Well Being.

Pass when: The screen says to connect the sensor before you begin. Retry or plugging it back in lets you continue.

Fail when: It pretends a measurement is running with no sensor.

Phone Charging

The visitor watches a short sponsored message, then plugs in. The screen follows the session until they finish or the safety limit is reached.

C1
Do: Tap Phone Charging and watch the sponsored message. Do not skip ahead.

Pass when: The message plays first. The socket is not offered for charging until that step finishes. Cancel during the message returns you without leaving the socket on.

Fail when: The socket turns on before the message, or Cancel leaves it on.

C2
Do: After the message, plug in a phone.

Pass when: The screen asks you to plug in, then shows that the phone is connected, with a session timer and the safety-limit time remaining.

Fail when: The phone draws power but the screen stays on “plug in”, or the socket never turns on.

C3
Do: While charging, tap Done charging.

Pass when: The socket turns off. The screen says charging is finished and you can go back home.

Fail when: Done leaves the socket powered, or you cannot leave the screen.

C4
Do: Unplug the phone during a charge, if it is safe to do so.

Pass when: The screen says the phone was unplugged and the socket is off.

Fail when: The socket stays on after the phone is unplugged and the screen still says it is charging.

C5
Do: Open Phone Charging with the charging controller disconnected.

Pass when: You get a clear error and a Retry button. The kiosk does not claim the phone is charging.

Fail when: The screen looks like a normal charge with no hardware attached.

Astrology

The hub offers four readings. Each one should end with Done, and Home should clear the details you typed.

A1
Do: Tap Astrology.

Pass when: You can choose My Kundali, Palm Insights, Match Kundalis, and Today & Periods. Cancel returns home.

Fail when: A reading is missing, or Cancel does not leave the hub.

A2
Do: Open My Kundali. Enter name, birth date, time, and place. Choose North Indian, draw the chart, then repeat with South Indian.

Pass when: Each style draws a birth chart. You can see lagna, sun, moon, and related details, then tap Done or New kundali.

Fail when: Draw kundali does nothing, or both styles look identical when you asked for the other.

A3
Do: Open Palm Insights with the USB camera connected. Place an open palm in the outline, capture it, and get a reading. Then retake.

Pass when: The camera preview appears. After capture you get on-screen guidance. Retake lets you shoot again.

Fail when: The camera stays black with no error, or Get reading runs with no photo.

A4
Do: Open Palm Insights with no camera connected.

Pass when: The screen says no camera was found, or that the camera could not be opened, and offers Retry camera.

Fail when: It shows a reading without a photo.

A5
Do: Open Match Kundalis. Enter the groom’s birth details, continue, then enter the bride’s details and match.

Pass when: You move from groom to bride. The result is a Gun Milan compatibility screen. New match clears both people.

Fail when: You can match with a name or birth place left blank, or the result mixes up the two people.

A6
Do: Open Today & Periods, enter birth details, and tap Get today’s reading.

Pass when: You see today’s panchang and the current dasha. Done returns you toward home.

Fail when: The reading has no panchang and no dasha, and does not say that details are unavailable.

Fuel stations

The kiosk lists petrol, diesel, CNG, and EV stations about 5 km around it, then hands directions to the visitor’s phone.

F1
Do: Tap Fuel stations.

Pass when: A list of nearby stations loads, described as about 5 km. Each row shows enough to tell stations apart, including distance.

Fail when: The list stays empty with no message, or it never finishes loading.

F2
Do: Filter by petrol, diesel, CNG, and EV, one at a time.

Pass when: The list changes to that fuel. A station that does not sell the selected fuel drops off the list.

Fail when: Every filter shows the same stations.

F3
Do: Tap one station.

Pass when: You get directions on a map and a QR code labelled for scanning on your phone. Scanning opens directions on the phone.

Fail when: The QR does not scan, or the map is for a different station than the one you tapped.

F4
Do: Tap Home from the station list or the directions view.

Pass when: You are back on the six-tile menu.

Fail when: The map stays up or the previous station is still open.
